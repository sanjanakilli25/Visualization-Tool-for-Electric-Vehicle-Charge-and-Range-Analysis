ABOUT THE PROJECT

Discover EVision

Transforming Electric Vehicle Data into Actionable Insights

EVision is an interactive web platform developed to visualize Electric Vehicle Charge and Range Analysis using Tableau. The project converts complex EV datasets into clear dashboards and stories, helping users understand battery capacity, charging behavior, driving range, energy efficiency, manufacturer performance, and EV adoption trends. It demonstrates how data visualization supports informed decisions and promotes sustainable transportation.
